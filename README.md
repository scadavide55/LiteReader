# LiteReader
LiteReader is a light, fast e-reader for old Android 4.0 tablets such as the Kindle Fire HD. A native engine opens huge manga and comic EPUB/CBZ files (1.8 GB) without lag. It also reads PDF, text EPUB, MOBI/AZW3, TXT and DOCX. It has a library, saved pages, bookmarks and pinch zoom. The APK is 3.5 MB.
